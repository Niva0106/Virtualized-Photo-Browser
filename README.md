
# Virtualized Photo Browser

A responsive photo browser built with **React, TypeScript, and TanStack Virtual**. Browse images from a local folder using a virtualized grid and a full-screen photo viewer.

## Live Demo

[Virtualized Photo Browser](https://virtualized-photo-browser.vercel.app)

## Features

- Select a local folder and automatically filter image files.
- Virtualized photo grid for efficient rendering of large collections.
- Responsive layout with 2, 3, or 4 columns.
- Full-screen photo viewer with keyboard navigation.
- Displays filename, file size, and image dimensions.
- Handles empty folders and images that fail to load.
- Object URL cleanup for memory management.
- Displays the number of currently rendered photos.

## Tech Stack

- React + TypeScript
- Vite
- TanStack Virtual
- HTML + CSS

## Virtualization

Uses **TanStack Virtual** to render only visible photo rows and a small number of additional rows (overscan), rather than rendering the entire collection at once.

This reduces DOM elements and improves performance when browsing large collections.

## Performance Testing

Tested with 20,000 photo entries generated by reusing the original local images with unique IDs.

This verifies virtualization behaviour but does not simulate the memory and decoding cost of 20,000 unique images.

## Run Locally

```bash
npm install
npm run dev
```

## Limitations

- Photos remain local and are not uploaded to a server.
- Folder selection depends on browser support.
- Performance depends on device and image sizes.
